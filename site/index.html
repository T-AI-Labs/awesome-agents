How it works

Collected weekly

Roles come from the import-tested companies of Awesome Paperclip Companies. Subagents come from openly licensed Claude Code collections, adapters from npm, projects from GitHub's top 100 searches for AI Agents, Claude, Claude Code and Paperclip. Runtimes and frameworks are picked by hand.

Ranked by real numbers

Stars, forks, open issues and the language come from GitHub. Activity counts commits on the default branch per week. Downloads come from npm and PyPI. GitHub no longer shares when a star was given, so growth is measured from our own weekly snapshots.

Runs in

Paperclip means you can import the role, hire the runtime through a built-in or community adapter, or install the adapter. Claude Code means a subagent file or a project that says it works there. For projects this is read from their description and topics, so check before you rely on it.

Stars of a role or subagent belong to the project it comes from. A popular repository does not prove that an agent does good work, and nothing here is a security review: agents act with the access you give them, so read one before you use it.
